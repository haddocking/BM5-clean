# HADDOCK-ready

The directory contains HADDOCK-ready files for each entry of BM5.
Each sub-directory (one per complex) contains the following files:

* `XXX_r_u.pdb` : Unbound receptor PDB
* `XXX_l_u.pdb` : Unbound ligand PDB
* `XXX_r_b-matched.pdb` : Matched bound receptor PDB
* `XXX_l_b-matched.pdb` : Matched bound ligand PDB
* `XXX_target.pdb` : the reference, matched bound complex (receptor chain A, ligand chain B)

And for each PDB there is an associated `.info` file providing statistics of the PDB content.

The bound and unbound forms of each partner have the same residues, with the same numbering and
residue types (receptor chain A, ligand chain B, numbered sequentially without insertion codes):

* Selenomethionines are MET (`ATOM` records, `SD`, element `S`); other modified residues are given
  as their parent residue (e.g. methyl-His as HIS, Cys sulfinic acid as CYS).
* Residues present in both the unbound and the bound PDB entries are included, also when they have
  alternate locations (conformation A is used) or insertion codes. Residues missing from either
  PDB entry are left out, as are residues of different type in the bound and unbound forms.
* `TER` records separate different chains (e.g. when two chains are merged into one) and
  co-factors, not chain breaks.
* Co-factors and ligands present in the unbound structures are kept as `HETATM`.

Two distance restraints files are present:

* `XXX_ambig.tbl` : Ambiguous interaction restraints for the true interface of the reference complex
  measured with a 3.9A cutoff, generated with `haddock-restraints ti XXX_target.pdb 3.9`
  (on the reference without `HETATM`)
* `XXX_ambig5.tbl`: Same with a 5.0A cutoff (`haddock-restraints ti XXX_target.pdb 5`)
* `XXX_hbonds.tbl` : If present, unambiguous restraints keeping together the disconnected parts of
  each unbound partner (chain breaks, merged chains and co-factors), generated with
  `haddock-restraints restraint` on `XXX_r_u.pdb` and `XXX_l_u.pdb` and concatenated.
  Absent when neither partner has chain breaks or co-factors.

And if there is a co-factor or ligand in the structure:

* `XXX_ligand.param` : the ligand parameter file as generated by PRODRG
* `XXX_ligand.top` : the ligand topology file as generated by PRODRG

Further each sub-directory contains an `ana_scripts` directory with the reference files for the analysis:

* `target-unbound.pdb` : the unbound complex (`XXX_r_u.pdb` and `XXX_l_u.pdb`, which are superimposed onto the reference complex)
* `target.contacts3.9` : intermolecular contacts at 3.9A cutoff
* `target.contacts5` : intermolecular contacts at 5A cutoff used for calculating the fraction of native contacts
* `target.izone` : the interface definition for i-RMSD calculations with ProFit (derived from all residue contacts at 10A)
* `target.izoneA` : same as `target.izone` but for chainA only
* `target.izoneB` : same as `target.izone` but for chainB only
* `target.lzone` : the zone definition for l-RMSD calculations with ProFit

For complexes with a symmetric partner (e.g. a homo-oligomer offering several equivalent binding
sites), `ana_scripts_2` (and `ana_scripts_3`, ...) contain the same files for the symmetry-related
reference complexes, in which one partner is placed on another binding site by a symmetry
operation of the other partner, so that models can be evaluated against each equivalent site:

* `target.pdb` : the symmetry-related reference complex
* `target.contacts5`, `target.izone`, `target.izoneA`, `target.izoneB`, `target.lzone` : as above

The `HADDOCK-ready/ana_scripts` directory contains the analysis scripts:

* `i-rmsd_to_xray.csh`: csh script to calculate i-RMSDs with ProFit from HADDOCK `file.nam` files
* `l-rmsd_to_xray.csh`: csh script to calculate l-RMSDs with ProFit from HADDOCK `file.nam` files
* `fraction-native.csh` : csh script to calculate the fraction of native contacts from HADDOCK `file.nam` files
* `cluster-fnat.csh` : a script that generate cluster stats including RMSD and Fnat values
* `run_all.csh` : a csh script that runs the complete analysis of all three stages of HADDOCK

Note that the paths in the various analysis scripts must be adapted to your directory structure.
This can be done by running the `HADDOCK-ready/scripts/setup-ana_scripts.csh` script with as argument the directory name of all entries

Finally, the `HADDOCK-ready` directory also contains pre-calculated i-RMSD values for the superimposed
unbound structures onto the reference complex and for each separate interface (ProFit, backbone atoms
N, CA, C and O over the `target.izone`, `target.izoneA` and `target.izoneB` zones):

* `i-RMSD.dat` : Interface RMSD unbound superimposed versus reference, sorted in the order of the directory listing
* `i-RMSD-sorted.dat` : Interface RMSD unbound superimposed versus reference, sorted from small to large
* `i-RMSD_r.dat` : Interface RMSD of the unbound receptor interface versus reference, sorted in the order of the directory listing
* `i-RMSD_r-sorted.dat` : Interface RMSD of the unbound receptor interface superimposed versus reference, sorted from small to large
* `i-RMSD_l.dat` : Interface RMSD of the unbound ligand interface versus reference, sorted in the order of the directory listing
* `i-RMSD_l-sorted.dat` : Interface RMSD of the unbound ligand interface superimposed versus reference, sorted from small to large

Other sub-directories:

* `scripts` : `setup-ana_scripts.csh`, to adapt the paths in the analysis scripts


# haddock3-scripts

Configuration files to run the benchmark with haddock3 using
[haddock-runner](https://github.com/haddocking/haddock-runner):

* `unbound-bench.yaml` : benchmark configuration with two scenarios starting from the unbound structures,
  all-atom (`all-atom_unbound`) and coarse-grained Martini 2 (`coarse-grain_unbound`), using the
  `XXX_ambig5.tbl` restraints and evaluating against `XXX_target.pdb`
* `input.list` : the list of unbound receptor and ligand PDB files of all complexes
* `haddock3.sh` : wrapper script calling `haddock3` (paths must be adapted to your installation)


# scripts

* scripts regenerating the `HADDOCK-ready` restraint and analysis files (contacts, ProFit zones,
  `XXX_ambig.tbl`, `XXX_ambig5.tbl`, `XXX_hbonds.tbl`, symmetry-related references, i-RMSD tables);
* `curation`: the scripts used to check the structures against the PDB entries and correct them.

See the README in that directory.


# Changes

The `HADDOCK-ready` files were checked against the PDB entries and corrected:

* Bound numbering matched to the unbound numbering where it differed (1OPH ligand, 1FAK and 1AZS
  receptors; the protomers 2 and 3 of the 4FQI ligand trimer were swapped in the bound form).
* Residues present in both the bound and unbound PDB entries but missing from both files were added:
  selenomethionines (as MET), other modified residues (as their parent residue), and residues
  with alternate locations or insertion codes. Remaining selenium atoms in MET were converted to sulfur.
* `TER` records at chain breaks were removed.
* `target-unbound.pdb` files were rebuilt from the current unbound files.
* The symmetry-related references (`ana_scripts_K`) were rebuilt from the current reference
  complexes with exact symmetry operations (except 1QFW, whose two hCG subunits are only
  pseudo-symmetric).
* Contacts, ProFit zones, `XXX_ambig.tbl`, `XXX_ambig5.tbl`, `XXX_hbonds.tbl` and the i-RMSD values were
  regenerated. The separate co-factor restraint files (`XXX_r_u_LIG.tbl`, `XXX_l_u_LIG.tbl`) are
  replaced by `XXX_hbonds.tbl`.
* Obsolete content was removed: `structures-matched` (superseded by `HADDOCK-ready`), `structures-orig.tgz`
  (the original BM5 files, available from [https://zlab.umassmed.edu/benchmark/](https://zlab.umassmed.edu/benchmark/)), `symmetries`,
  the HADDOCK 2.4 run and statistics scripts, the original preparation scripts and the old
  restraint-generation scripts (replaced by `haddock-restraints`), and the Martini coarse-grain
  models (`XXX_r_u_cg.pdb`, `XXX_l_u_cg.pdb`) with their `XXX_cg_to_aa.tbl` restraints, which haddock3
  generates on the fly (`topocg` module).
