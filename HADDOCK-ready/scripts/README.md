# HADDOCK related scripts

* `setup-ana_scripts.csh` : when cloning this repo, run this script to correct the path in all analysis scripts (takes as argument the name of the complex directory)

The scripts regenerating the restraint and analysis files of `HADDOCK-ready` are in the top-level
`scripts` directory. Configuration files for running the benchmark with haddock3 are in `haddock3-scripts`.
